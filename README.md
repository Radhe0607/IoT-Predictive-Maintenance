# IoT Predictive Maintenance

Manufacturing & Automotive Predictive Maintenance using Machine Learning.

Project developed during the Infotact Solutions Data Science & Machine Learning Internship.


## Project Workflow

1. Load the dataset
2. Clean the data
3. Create useful features
4. Train the machine learning model
5. Evaluate the model
6. Predict equipment failure
